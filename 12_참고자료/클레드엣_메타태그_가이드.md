# 클레드엣 상품 메타태그 가이드

## 상품별 title / description 작성 예시

| 상품 | title | description |
|------|-------|-------------|
| 리네아 뱀부 랩 세트 | `리네아 뱀부 랩 세트 - 대나무 소재 라운지웨어 \| 클레드엣` | 시원한 대나무 소재 랩 디자인 세트. 여름 홈웨어, 수유복으로도 활용 가능합니다. |
| 에떼르 면모달 나시 | `에떼르 면모달 나시 - 부드러운 면모달 홈웨어 \| 클레드엣` | 피부에 닿는 순간 느껴지는 부드러움. 면모달 소재 데일리 이너웨어. |

## 작성 공식

- **title** → `상품명 - 소재/특징 | 클레드엣`
- **description** → `소재 + 특징 + 누구에게 좋은지` 한 줄로

## 팁

- 상품이 21개이므로 하루에 5개씩 4일이면 완료됩니다.
- 모든 페이지의 title이 서로 달라야 합니다.
- 고객이 검색할 만한 단어를 넣으세요 (라운지웨어, 홈웨어, 수유복, 천연소재 등).
- 브랜드명은 title 맨 뒤에 배치하세요.
