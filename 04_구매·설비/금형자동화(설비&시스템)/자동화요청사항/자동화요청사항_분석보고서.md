## 2. 설비별 자동화 요구사항

### 2-1. Sodick 방전가공기 (EDM)

| No. | 기능 | 상세 설명 | 중요도 |
|-----|------|----------|--------|
| 1 | 이더넷 포트 (하드웨어) | 네트워크 연결용 LAN 포트 | 필수 |
| 2 | 자동 승강 오일조 | 코드로 오일조 높이 제어 가능 | 필수 |
| 3 | 자동화 인터페이스 | 6485 포트 — 프로그램 업로드, 설비 모니터링, 원격 시동 | 필수 |
| 4 | MR 헤드 (C축) | 없으면 자동화 가공 시 제약 多 → 발주 전 사전 확인 필수 | 필수 |
| 5 | 항공 커넥터 | EROWA A타입 공작물/전극 교환기 입출력 인터페이스 | 필수 |
| 6 | 매크로 변수 기능 | 표준 사양 | 필수 |
| 7 | 주축 공압 척 (에어 밀봉공 포함) | 밀봉공 없으면 **안전 위험** 발생 | 필수(안전) |

> ⚠️ **주의:** C축(MR 헤드) 미탑재 시 자동화 가공에 상당한 제약이 발생하므로 발주 전 자동화 업체와 사전 협의 필수.

---

### 2-2. Makino 머시닝센터 (CNC)

| No. | 기능 | 상세 설명 | 중요도 |
|-----|------|----------|--------|
| 1 | 이더넷 포트 (하드웨어) | — | 필수 |
| 2 | 자동 측면문 | 전면문보다 측면문 권장 — 로봇 작업 편의성 우수 | 필수 |
| 3 | MML 인터페이스 | 고속 이더넷 인터페이스 (FAST ETHERNET) | 필수 |
| 4 | 좌표 회전 기능 | G68 좌표계 회전 (COORDINATE SYSTEM ROTATION) | 필수 |
| 5 | 항공 커넥터 (EROWA A타입) | 공작물 교환기 입출력 인터페이스 | 필수 |
| 6 | 매크로 변수 기능 | Custom Macro 공용 변수 1100 (표준) | 필수 |
| 7 | 3/4번째 참조점 복귀 기능 | 3RD & 4TH REFERENCE POSITION RETURN | 필수 |
| 8 | 기내 공구 측정기 (하드웨어) | 없으면 공구 파손 감지 불가 → **안전 위험** (자동화 논리엔 영향 없음) | 필수(안전) |
| 9 | 작업대 척용 에어 배관 | 6개, Φ6mm — 옵션이나 권장 (미비 시 배선 미관 불량) | 권장 |
| 9 | 공구 매거진 | 30개 이상 권장 (강제 아님) | 권장 |
| 10 | 확장 공구 번호 400개 | 기외 공구 교환 미사용 시 불필요 | 조건부 |

### 2-3. CMM 3좌표 측정기

| No. | 기능 | 상세 설명 | 중요도 |
|-----|------|----------|--------|
| 1 | 이더넷 포트 (하드웨어) | CMM PC에 LAN 전용 포트 별도 필요 | 필수 |
| 2 | 프로그램 호출 인터페이스 | **API 자료 제공 필수** — 제조사에 별도 요청 필요 | 필수 |
| 3 | 설비 상태 모니터링 인터페이스 | 설비 상태·좌표·실행 프로그램명 모니터링 — **API 자료 필수** | 필수 |
| 4 | 설비 원격 제어 인터페이스 | 원격 프로그램 선택·원격 시동 — **API 자료 필수** | 필수 |
| 5 | 비상정지 라인 (하드웨어) | 없으면 **안전 위험** — 반드시 배선 필요 | 필수(안전) |
| 6 | 프로브 교환 랙 | 전극·공작물 빈번한 프로브 교환 시 권장 | 권장 |
| 7 | 자동 측정 헤드 | 측정 각도 전환이 잦을 경우 권장 | 권장 |

> ⚠️ **주의:** CMM은 타 설비 대비 API 의존도가 높습니다. 항목 2·3·4 모두 CMM 제조사(Hexagon, Zeiss 등)로부터 API 문서를 사전에 확보해야 자동화 연동이 가능합니다.

### 2-4. CNC 머시닝센터 (범용 상세판 — 구비 여부 점검표)

문서 2-2(Makino)의 상세 확장판으로, "구비 여부" 확인 컬럼이 있는 현장 점검표 형식입니다.

| No. | 기능 | 주요 상세 내용 | 중요도 |
|-----|------|--------------|--------|
| 1 | 이더넷 포트 | 설비 통신용 | 필수 |
| 2 | 설비 메모리 | 원격 프로그램 업로드 시 100MB 이상 필요 (CF카드 연동 시 완화 가능) | 필수 |
| 3 | 자동 측면문 | 코드로 개폐 제어 가능해야 함 / 없으면 로봇이 직접 제어 | 필수 |
| 4 | 프로그램 업로드 인터페이스 | TCP/IP (API 또는 FTP 방식) + 삭제 API (매크로 프로그램 삭제 금지 제한 필수) | 필수 |
| 5 | 설비 상태 모니터링 | 실행 프로그램명 / 운전·정지·알람 / 알람 번호·내용 / 기계 좌표 / 공구 수명 / 주축 부하·공구번호·이송·회전수 | 필수 |
| 6 | 설비 원격 제어 | 원격 프로그램 선택·시동 / 원격 Reset | 필수 |
| 7 | 좌표 회전 기능 | 측면문 투입 시 필요 / CNC+EDM 혼합 라인은 레이아웃에 따라 판단 / 5축 CNC는 불필요 | 조건부 |
| 8 | 자동화 안전 교환 신호 | 주축 이동 완료 신호 / 자동문 개폐 신호 / 로봇 진입 시 주축 잠금 (전기 도면·타임차트 제공 필요) | 필수(안전) |
| 9 | 매크로 변수 기능 | — | 필수 |
| 10 | 기내 공구 측정기 | 없으면 공구 파손 감지 불가 → 안전 위험 | 필수(안전) |

## 4. 안전 위험 항목 요약

자동화 연동 시 아래 항목이 미비하면 **안전 사고 위험**이 있습니다. 발주 및 시공 시 반드시 확인이 필요합니다.

| 설비 | 안전 위험 항목 | 비고 |
|------|--------------|------|
| EDM | 주축 공압 척 에어 밀봉공 미비 | 원래 공장 설치 척은 보통 포함, 비표준 설치 시 확인 필요 |
| CNC | 기내 공구 측정기 미설치 | 자동화 논리엔 영향 없으나 공구 파손 감지 불가 |
| CMM | 비상정지 라인 미배선 | 하드웨어 필수 — 없으면 긴급 정지 불가 |
| CNC (범용) | 기내 공구 측정기 미설치 / 안전 교환 신호 미구성 | 로봇 진입 시 주축 잠금 신호 없으면 충돌 위험 |

## 5. 후속 조치 권고

1. **CMM 제조사 API 확보** — 프로그램 호출·상태 모니터링·원격 제어 3개 항목 모두 API 자료가 필요하므로 CMM 구매 계약 시 API 제공 조건을 명시할 것.
2. **EDM C축(MR 헤드) 탑재 여부 확인** — 미탑재 시 자동화 업체와 사전 협의 후 대안 방안 도출 필요.
3. **각 설비 구비 여부 현황 파악** — 문서 4(CNC 범용 상세판)의 "구비 여부" 컬럼이 공란으로 되어 있음. 현장 확인 후 기입 필요.
4. **전기 도면·타임차트 준비** — 자동화 안전 교환 신호 구성 시 CNC 제조사로부터 관련 전기 도면을 사전 확보할 것.
