# AI 관련 서비스를 조사중입니다. 제미나이 챗GPT 클로드 같은 핵심 AI 엔진을 갖고있는 서비스와 젠스파크 퍼플렉시티 스카이워크 등 에이전트 서비스 또는 로컬 서비스 가능 AI를 구분하여 정리해주세요. 각각의 장단점 및 비용 부분을 확인해주세요

핵심 LLM 엔진(챗GPT·제미나이·클로드)과 에이전트/메타 서비스(젠스파크·퍼플렉시티·스카이워크 등)를 나눠 보시면 됩니다.[^1][^2]

## 1. 크게 나누는 기준

- **핵심 엔진형 서비스**: 자체 LLM을 가진 제공사
    - OpenAI ChatGPT (GPT 계열)
    - Google Gemini
    - Anthropic Claude
- 에이전트·메타·로컬 서비스:
    - 젠스파크(GenSpark): 여러 모델을 엮어주는 에이전트/올인원 워크스페이스[^3][^4][^5]
    - 퍼플렉시티(Perplexity): 검색+요약 특화 답변 엔진[^6][^7][^8]
    - 스카이워크(국내 에이전트/워크플로우 계열로 추정, 여러 모델 연동형 서비스로 분류)

(스카이워크는 서비스별 스펙이 여러 개라, 여기서는 “여러 LLM을 연결해 업무 프로세스를 자동화하는 국산 에이전트/오케스트레이션 계열”로 보시면 됩니다.)

## 2. 핵심 엔진 서비스 요약

| 항목 | ChatGPT | Claude | Gemini |
| :-- | :-- | :-- | :-- |
| 개발사 | OpenAI | Anthropic | Google |
| 강점 | 범용성, 생태계, 코드·자동화 | 긴 문서·추론·안전성[^9] | 구글 서비스/검색 통합, 멀티모달[^10] |
| 약점 | 실시간 웹은 제한적, 검색 특화 아님[^4] | 방어적, 사용량 제한 타이트[^11][^9] | 한국어 UI·요금제 구조 아쉬움 평가[^11][^10] |
| 대략 요금 | Plus/Pro 월 20달러 급[^4][^10] | Pro 월 20달러 급[^4][^10][^9] | Advanced/Premium 월 20달러 급[^4][^10] |

### 장단점 (B2B 관점)

- 장점
    - 자체 **API** 제공: 사내 서비스에 직접 임베딩 가능.
    - 엔진 선택권: 필요 시 “엔진을 바꾸는” 수준의 아키텍처 설계 가능.
    - 모델 버전·성능·가격을 직접 최적화하기 쉬움.
- 단점
    - 프롬프트 설계·에이전트 설계·UI/권한/로깅 등 **모든 껍데기를 직접** 만들어야 함.
    - 컨트롤·감사·접속제어 등 엔터프라이즈 요구사항은 별도 구현 필요.

## 3. 에이전트·메타·검색/로컬 계열

### 3-1. 젠스파크 (GenSpark)

- 성격: 여러 AI 모델(챗GPT·클로드·제미나이 등)을 한 워크스페이스에서 호출, 검색·PPT·시트·문서·이미지·영상까지 생성하는 올인원 에이전트 플랫폼.[^4][^5][^3]
- 주요 기능
    - AI 검색, AI 슬라이드(PPT 자동 생성), AI 시트(데이터 분석·차트), AI 문서, 이미지·영상 생성.[^4]
    - MoA 기반 검색·에이전트 실행, 자율적으로 “행동하는” 워크플로우 지향.[^5][^4]
- 과금
    - 프리미엄 구조: 무료+유료 Pro.[^5]
    - Pro: 월 약 20~25달러, 10,000 크레딧 제공.[^4][^5]
    - 기능별 크레딧 차감 방식.[^4]
- 장점
    - 사내 제안서, 리포트, 슬라이드, 데이터 분석까지 **업무산출물 중심** 에이전트.[^3][^4]
    - “모델 통합 레이어”로 이미 구현돼 있어서 IT팀이 별도 에이전트 프레임워크를 안 짜도 됨.
- 단점
    - 크레딧 기반이라 헤비유저가 많으면 사용량 관리 필요.[^4]
    - 내부 시스템 연동·온프레미스 요구에는 제약 가능성(클라우드 SaaS 중심).

***

### 3-2. 퍼플렉시티 (Perplexity)

- 성격: 실시간 검색+요약 특화 Q\&A 엔진, 검색형 LLM 브라우저.[^7][^8][^12][^6][^4]
- 특징
    - 실시간 웹 검색 후 출처를 명시해 답변, “AI 기반 검색엔진” 성격.[^6][^7][^4]
    - 검색 정확도·출처 투명성이 강점으로 평가.[^8][^7]
- 과금
    - 무료 플랜 + Pro 월 20달러 수준이 일반적 비교(다른 메이저와 유사 가격대로 언급).[^12][^4]
- 장점
    - 자료조사, 레퍼런스 확인, 업계 동향 정리 등에 최적.[^7][^8][^4]
    - 인용·출처가 명확해서 내부 보고서 초안 만들 때 근거 정리에 좋음.[^7][^4]
- 단점
    - 젠스파크처럼 PPT·시트·문서 편집 툴이 통합된 “올인원 오피스”는 아님.[^5][^4]
    - 에이전트 워크플로우(멀티스텝 업무자동화)는 제한적; 검색·요약 중심.[^5]

***

### 3-3. 스카이워크 및 기타 에이전트/로컬

- 스카이워크: 국내에서 여러 LLM을 붙여 업무 에이전트·워크플로우를 만드는 SaaS/솔루션 계열로 분류 가능(구체 스펙은 서비스별 상이).
- 공통적인 에이전트/로컬형 서비스 특징[^2][^1]
    - 여러 LLM 엔진을 백엔드로 선택·조합.
    - 메모리, 툴 사용(API 호출, DB, 사내 시스템), 워크플로우(다단계 태스크)를 제공.
    - 일부는 온프레미스 혹은 VPC 배포 지원 → 데이터 거버넌스 요구 대응.
- 장점
    - 엔진 의존도를 낮추고, “우리 회사 업무 프로세스” 관점에서 추상화 가능.
    - 내부 시스템과 연동 시 “에이전트 허브” 역할.
    - 로컬 배포/사내망 운영이 가능한 제품 선택 시 보안·규제 측면 유리.
- 단점
    - 제품마다 커스터마이징 난이도·SDK 품질 편차가 큼.
    - 결국 백엔드로 쓰는 LLM 비용(토큰단가)+플랫폼 구독료 둘 다 고려해야 함.

## 4. 핵심 엔진 vs 에이전트/메타/로컬: IT 관점 정리

### 개념 비교

| 구분 | 핵심 LLM 엔진 (ChatGPT·Claude·Gemini 등) | 에이전트/메타/로컬 (GenSpark·Perplexity·Skywalk 등) |
| :-- | :-- | :-- |
| 목적 | 텍스트·코드·멀티모달 생성 | 목표 달성·업무 자동화·검색/산출물 생성[^1][^2] |
| 주체 | 모델 제공사(OpenAI·Google·Anthropic) | 모델을 **활용**하는 서비스/플랫폼 |
| 인터페이스 | API·웹 챗 | 워크스페이스, 슬라이드/시트·검색·플로우 UI[^3][^4][^5] |
| 장점 | 자유로운 임베딩, 세밀한 튜닝·옵션 | 바로 업무에 쓰기 쉬운 기능, 멀티모델 활용[^3][^4][^5] |
| 단점 | 모든 업무 로직을 직접 설계 | 커스터마이징 한계, 라이선스 구조 복잡 |

### 비용 측면

- 핵심 엔진
    - “월 구독(웹 사용)” + “API 토큰 사용량” 이중 구조.
    - B2B에서는 대부분 API 단가(입출력 토큰·컨텍스트 길이·모델 등급)를 기준으로 TCO 산정.
- 에이전트/메타/로컬
    - 젠스파크처럼 월 정액+크레딧제(내부에서 여러 모델 호출 비용 포함).[^5][^4]
    - 퍼플렉시티처럼 Pro 구독 + 내부에서 필요한 검색·모델 호출을 추상화.[^12][^4]
    - 온프레미스/엔터프라이즈 솔루션은 좌석기반+용량제 혼합 등 다양한 계약 구조.

## 5. 어떤 경우에 무엇을 쓰면 좋은지 (관리자/엔지니어 관점)

- “사내 시스템에 AI 기능을 직접 넣고 싶다”
    - → 핵심 엔진(ChatGPT API·Claude API·Gemini API 등)을 1차 고려.
    - 필요시 여러 엔진을 추상화하는 사내 “LLM 프록시 레이어” 구축.
- “기존 인력에게 바로 쓸 수 있는 도구를 배포하고 싶다 (제안서·보고서·분석 등)”
    - → 젠스파크 같은 올인원 에이전트 워크스페이스를 1차 고려.[^3][^4][^5]
- “리서치·검색 정확도와 출처가 중요하다”
    - → 퍼플렉시티 + 필요시 별도 LLM 조합.[^8][^6][^7][^4]
- “국내 인프라·사내망·규제(예: 고객정보, 회계데이터) 고려해야 한다”
    - → 스카이워크류 국산 에이전트/워크플로우 플랫폼 또는 자체 로컬 LLM+오케스트레이션 검토.

현재 고민 중이신 용도가 “직원용 업무툴 배포”인지 “사내 시스템(웹/앱/ERP 등)에 직접 AI 기능 임베딩”인지에 따라 추천 구성이 많이 달라지는데, 어느 쪽이 더 우선인가요?
