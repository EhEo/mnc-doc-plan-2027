## Scenario A: 현행 구조 유지 + 부분 최적화

### A-1. 구조 개요

```
[한국 대주주 2인]
       ↓ (지분 직접 보유)
[싱가포르 법인 A] ←→ [싱가포르 법인 B]
    ↓ (100%)              ↓ (100%)
[베트남 제조법인]      [한국 사무소]
[중국 사무소]          (→ 한국 신규 공장)
```

**핵심 최적화 조치:**
1. 베트남 법인: 하이테크 기업(HTET) 인증 또는 지원산업 등록 → 10% 우대세율 신청 (**단, 전자부품·자동차부품이 지원산업 제품 리스트에 포함되는지, 국내 미생산 조건 및 기술표준 충족 여부를 베트남 현지 전문가와 선행 확인 필요**)

**K-CFC 상충 문제.** 싱가포르 법인 ETR을 10%로 낮추면 K-CFC 기준(15% 이하)을 충족하여 대주주에게 유보소득 합산과세가 적용될 수 있다. 해결책은 ① 국조법 제27조의2 실질 사업 수행 제외 요건 충족, 또는 ② 정기적 배당 실시로 K-CFC 적용 소득 최소화.

### A-6. 한국 대주주 개인 단계 세부담

베트남 이익 USD 100을 한국 대주주까지 송금하는 세부담 시뮬레이션.

**법적 전제 (소득세법·국조법 기준):**
- 싱가포르 국내법상 배당 WHT: **0%** (1-tier 과세 체계)
- 직접 FTC (소득세법 제57조 제1항): 외국에서 실제 징수된 세금만 공제 가능 → 싱가포르 WHT 0%이므로 직접 FTC **없음**
- 간접 FTC (국조법 제30조): 외국자회사 납부 법인세 공제는 **내국법인** 한정 → **개인 주주 적용 불가** (대법원 2015두47737 참조)
- 따라서 베트남 CIT는 개인 주주의 한국 소득세에서 **공제되지 않음** → 경제적 이중과세 발생

**A 최적화 시나리오 (베트남 10% + 싱가포르 참여면제):**

| 단계 | 금액 | 세금 | 세후 |
|------|------|------|------|
| 베트남 EBIT | 100 | CIT 10 (10%) | 90 |
| 베트남→싱가포르 배당 | 90 | WHT 0% (VN 국내법) | 90 |
| 싱가포르 수취 (참여면제) | 90 | 0 (ITA §13(8)) | 90 |
| 싱가포르→한국 대주주 배당 | 90 | **WHT 0% (SG 국내법)** | 90 |
| 한국 종합소득세 | 소득 90 | 90 × 49.5% = 44.55 | — |
| 직접 FTC | — | 0 (외국 WHT 없음) | — |
| **총 세금** | | **10 + 0 + 44.55 = 54.55** | |
| **개인 단계까지 실효세율** | | **~54.6%** | |

**Baseline (베트남 20%):**
- 베트남 CIT 20, 싱가포르 수취 80, 한국 개인 세금 80 × 49.5% = 39.6
- 총 세금: 20 + 39.6 = **59.6%**

**개인 단계 절감 효과:** ~5%p (베트남 CIT 인하의 직접 효과만 반영. 간접 FTC 미적용으로 법인 단계 절감의 절반만 개인에게 전달됨.)

### A-7. 미국 투자자 유치 용이성

**🔴 적합하지 않음**

- 싱가포르는 배당 WHT 없음(0%). 그러나 미국 기업 투자자가 싱가포르 법인을 지배할 경우 **GILTI(Global Intangible Low-taxed Income)** 또는 **Subpart F** 규정에 따라 미국 투자자 단계에서 싱가포르 법인 소득이 합산과세될 수 있음
- 미-싱 조세조약 미체결로 GILTI/Subpart F 적용 완화를 위한 조약상 예외 이용 불가
- Due Diligence 시 A·B 분리 구조, 중국 사무소 PE 리스크 등 구조적 취약점 노출

### B-6. 한국 대주주 개인 단계 세부담

Scenario A와 동일한 베트남→싱가포르→한국 흐름 유지. 한국 신규 공장의 이익은 싱가포르 법인에 배당 후 동일 경로로 흐름.

**한국 공장→싱가포르 배당 WHT:** 한-싱 조약 10% (지분 25% 이상 보유 시)

전체 개인 단계 ETR은 Scenario A와 동일 구조 (~54.6%, 베트남 10% 최적화 시나리오 기준). 한국 공장 이익이 추가될 경우 개인 단계 세부담이 소폭 상승할 수 있음.

### B-7. 미국 투자자 유치 용이성

**🟡 부분적으로 개선 (구조 단순화 효과)**

- 싱가포르-미국 조약 미체결 문제는 여전히 미해결
- 다만 구조 단순화로 Due Diligence 부담 감소
- 미국 투자자가 싱가포르 통합 법인에 투자 시: 싱가포르 국내법상 배당 WHT **0%**이므로 WHT 자체는 없음. 다만 미국 투자자가 CFC(제어외국법인) 보유 시 **GILTI/Subpart F** 과세 위험 별도 검토 필요
- 권고: 미국 투자자 유치 확정 시 Scenario B → C 순차 전환 계획 수립

**Scenario C-HK (권고: 아시아 중심 전략 시)**
- **추천 이유:** 가장 높은 순절감 ROI(USD 2.6-2.8M). 낮은 설립·유지 비용, 영국법 기반 법체계.
