## 2. 투자 구조 선행 확인 사항 {#2}

### 2-1. 300억의 자금 흐름 — 반드시 계약 전 확인

분석 전 가장 먼저 파악해야 할 사항입니다. 300억이 어디로 투입되느냐에 따라 리스크의 성격이 완전히 달라집니다.

| 시나리오 | 구조 설명 | 위험 수준 |
|---|---|---|
| **A. 프로젝트 추가 에쿼티** | 300억이 사업비에 투입되고 투자자가 지분 취득 | 중간 — 사업 성패와 직결 |
| **B. 기존 투자자 지분 매입** | 기존 투자자가 300억을 수취하고 49% 지분을 양도 | **고위험** — 기존 투자자가 리스크를 매각하는 구조 |
| **C. 대여금 형태** | 사실상 무담보·후순위 대출 | **매우 고위험** — 에쿼티 보호 없음 |

> **시나리오 B가 가장 흔히 발생하는 투자 함정입니다.** 기존 투자자가 사업 초기 위험을 감수하며 진행하다가 어느 시점에 지분을 프리미엄에 매각하는 구조입니다. 계약서에 "지분 양수도" 문구가 있으면 시나리오 B에 해당합니다.

### 2-2. 현재 자기자본 구조와의 정합성

기존 수지분석(2025.01.23 기준)상 자기자본은 **380억원**으로 계획되어 있습니다.

| 의문 사항 | 확인 필요 이유 |
|---|---|
| 380억 중 이미 납입된 금액은 얼마인가 | 미납입분이 있다면 투자자의 300억이 그 공백을 메우는 구조일 수 있음 |
| 기존 투자자의 실제 투입액은 얼마인가 | 기존 투자자가 소액 투입 후 대규모 지분을 보유 중이라면 불공정 구조 |
| 300억 투입 후 총 에쿼티는 680억인가 | 수지분석상 380억만 필요한데 680억이 되면 잉여 자본 운용 계획을 확인해야 함 |

## 3. 상대방 수익 주장 800억 신뢰도 분석 {#3}

### 3-1. 기존 분석(v3.1)과의 비교

```
기존 보고서 Base case 사업수지:  708.02억원 (연면적 대비 21.85%)
상대방 주장 수익:                 800.00억원
차이:                            +91.98억원 (+13.0%)
```

상대방이 주장하는 800억은 이미 낙관적 가정으로 도출된 기존 보고서 Base case보다 13% 높은 수치입니다.

### 3-2. 800억 달성 조건 (모두 동시 충족 필요)

| 조건 | 현재 상태 | 충족 가능성 |
|---|---|---|
| HUG 저리 융자 성공 (Tr.A-1 650억@2.2%, Tr.A-2 1,010억@5.0%) | 주거비중 43.87%로 HUG 70% 요건 미달 → **적격성 미확정·고위험** | 낮음 |
| 분양가 계획 100% 달성 | 사상구 오피스텔 75.5%, 상가 10.2% 분양률 시장 현실 감안 시 도전적 | 낮음~중간 |
| 공사비 계획치 유지 (6,500천원/평) | 시장 대비 15~30% 저가 책정 → 초과 위험 존재 (+226~452억) | 낮음 |
| 분양세대수 확정 | 업무 252호(수지분석) vs 305~320호(IR) 불일치 미해소 | 불명확 |
| 미독해 서류 (PDF#4) 이상 없음 | `사상 기업지원복합센터 서류_25.02.13` 내용 미확인 | 불명확 |

### 3-3. 시나리오별 확률 분포

| 수익 구간 | 추정 확률 | 근거 |
|---|---|---|
| **800억 이상** | **10~20%** | HUG 미확정·공사비 초과·분양 불확실성 삼중 병목 |
| 400~799억 (Base~시장보정 사이) | **35~45%** | HUG 조건부 성공, 분양 일부 지연 |
| 100~399억 | **20~30%** | HUG 실패 시 금융비용 급증 (+200~300억) |
| 손익분기 이하 (0 미만) | **15~25%** | 복합악재 시나리오 — 보고서 △360.82억 |

> **종합 판단: "800억"은 10~20% 확률의 최적 시나리오입니다. 상대방이 이 수치를 확정 수익처럼 제시한다면 중대한 과장으로 봐야 합니다.**

## 5. 자본 구조 공정성 평가 {#5}

### 5-1. 자본 기여 대비 수익 배분

기존 투자자가 수지분석상 380억원을 이미 투입했다고 가정.

| 항목 | 기존 투자자 | 투자자 (검토자) |
|---|---|---|
| 투입 자본 | 380억원 | 300억원 |
| 총 에쿼티 대비 자본 비중 | **55.9%** | **44.1%** |
| 취득 지분율 | **51%** | 49% |
| 수익 배분율 | **50%** | 50% |
| Base case 수취액 (절대액) | **354억원** | 354억원 |
| 투입자본 대비 수익률 (Base case) | **93.2%** | **18.0%** |

### 5-2. 구조적 불균형 요약

동일 금액(354억원)을 받는 두 투자자의 실제 조건은 다음과 같이 크게 다릅니다.

- **기존 투자자**: 380억 투입 → 354억 수익 → ROI **93.2%** (3.5년)
- **투자자(검토자)**: 300억 투입 → 354억 수익 → ROI **18.0%** (3.5년)

> 기존 투자자는 투자자(검토자)보다 **5.2배 높은 수익률**을 가져가는 구조입니다. 이 불균형은 협상 재조정의 근거가 됩니다.

### 5-3. 공정 조건 도출 (참고)

투자자(검토자)가 기존 투자자와 동등한 리스크-리턴 구조를 갖추려면:

| 조정 방향 | 내용 |
|---|---|
| 수익 배분율 상향 | 50% → 60~65%로 조정 (자본 비중 44.1%에 비례한 보상) |
| 원금보장 조항 추가 | 사업 실패 시 기존 투자자가 300억 원금 우선 보전 |
| 우선 배당권 설정 | 300억에 대해 연 8% 우선 배당 후 잔여 수익 배분 |
| 담보 설정 | 토지 또는 건물에 대한 근저당권 설정 |

## 7. 투자 전 필수 확인 과제 7선 {#7}

### Task 1. 계약서 원문 입수 및 법무 검토

**목적:** 300억의 법적 성격 확정 및 투자자 보호 조항 확인.

확인 항목.
- 300억의 성격: 에쿼티 투자 vs 지분 양수도 vs 대여금
- 원금 손실 시 책임 한계 및 손실 분담 비율
- 수익 지급 조건: 분양 완료 후 vs 공사 완료 후 vs 준공 후 입주 완료 후
- 사업 실패·지연 시 투자자의 Exit 권리

예상 비용: 법무법인 계약서 검토 500~1,500만원.

### 8-1. 상대방 주장 요약 및 현실성 평가

| 평가 항목 | 평가 결과 |

### 8-3. 투자 권고 등급

> ### ⚠️ 조건부 협상 재조정 후 재검토 (현 조건 그대로 투자 불가)

현재 제시된 조건(300억/49%/50%)은 다음의 두 가지 이유로 수용하기 어렵습니다.

**이유 1 — 수익률 불균형.**
동일 금액을 수취하면서도 투자자는 기존 투자자 대비 5.2배 낮은 수익률을 가져가는 구조입니다.

**이유 2 — 구조적 리스크 미해소.**
토지 소유권(SR-3), HUG 적격성(SR-4), 신탁 보호 수준(SR-2) 등 5개 핵심 리스크가 해소되지 않은 상태입니다.

### 8-4. 투자가 정당화되는 6가지 조건

모두 충족 시에 한하여 재검토 가능합니다.

| # | 조건 |
|---|---|
| ① | 등기부 확인 → 부산도시공사 아닌 시행사 명의로 소유권 이전 완료 확인 |
| ② | HUG 사전상담 → 현 비주거 비중으로 PF 보증 가능 공식 통보 수령 |
| ③ | 신탁 구조 확인 → 투자자 원금이 분양대금 신탁계좌에서 우선 보호 확인 |
| ④ | PDF#4 서류 확인 → 숨겨진 채무·공공 의무 사항 없음 확인 |
| ⑤ | 분양 세대수 수지분석 기준 일치 확인 또는 차이 설명 납득 가능 |
| ⑥ | 협상 재조정 → 원금 보장 조항 또는 수익 배분 60~65%로 조정 |

### 8-5. 최종 경고
