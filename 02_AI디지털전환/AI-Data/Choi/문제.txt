과제 목적

본 과제는 실제 산업 현장에서 머신러닝이 어떻게 활용되고 있는지 조사하고,
그 사례를 이해 가능한 방식으로 정리하며, 나아가 본인의 관점을 더해 분석하는 것을 목표로 합니다.

작성 시 필수 조건

0. 정확성 

- 사실과 다른 내용이 포함되어서는 안 됩니다.
- AI 도구 사용 시 발생할 수 있는 환각(hallucination)에 각별히 주의하시기 바랍니다.
- 반드시 해당 사례를 확인할 수 있는 신뢰 가능한 출처를 명시해야 합니다.

평가 기준

1. 적절성 — 머신러닝 사용 사례인가?

- 단순한 자동화나 API 사용 사례는 해당하지 않습니다.
- 실제로 머신러닝 모델이 학습을 통해 문제를 해결한 사례여야 합니다.
- 수업에서 다룬 머신러닝 기법을 우선적으로 권장합니다.
- 딥러닝 또는 휴리스틱 기반 방법도, 그 원리를 명확히 설명할 수 있다면 허용됩니다.
- 단, LLM API를 단순 호출하는 방식의 사례는 인정되지 않습니다.

2. 가독성 — 데이터와 방법론 설명의 명확성

- 해당 사례에서 사용된 데이터의 종류와 특징
- 적용된 모델 또는 학습 방법
- 어떤 방식으로 문제를 해결했는지
- 위 내용을 다른 사람이 이해할 수 있도록 설명해야 합니다.
- 수학적으로 엄밀한 해석은 필요하지 않지만, 무엇을 어떻게 학습했는지는 드러나야 합니다.

3. 확장성 — 개인 관점의 해석 포함

- 단순히 사례를 요약/전달하는 것으로 끝나서는 안 됩니다.

- 나라면 이 문제를 이렇게 접근했을 것 같다
- 이 부분은 이렇게 개선할 수 있을 것 같다
- 다른 데이터나 모델을 사용한다면 어떤 결과가 나올까
- 해당 기술의 한계나 윤리적 고려사항 등

이 항목은 정답이 있는 부분이 아니므로, 내용의 타당성보다는 본인의 분석과 생각이 포함되었는지 여부를 평가합니다.
