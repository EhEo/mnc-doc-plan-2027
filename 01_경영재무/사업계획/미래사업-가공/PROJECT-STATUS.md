## 4. 핵심 분석 결론

### 4-1. 진입 가능성 판정

| 항목 | 판정 |
|------|------|
| 진입 매력도 | **높음** — DLC 급성장, 베트남 현지 Tier-1 공장 capa 부족 |
| 진입 난이도 | **중상** (QMS·검사·capa 선결로 일부 완화, 하지만 AVL·후공정·구리양산은 잔존) |
| 가장 빠른 경로 | AVC(하남)·Cooler Master(박닌) **베트남 현지 법인** 직접 접촉 |

### 4-2. 부품군별 진입 속도

| 부품 | 속도 | 이유 |
|------|------|------|
| 구조 브래킷·레일·트레이 | **빠름** (견적·샘플 즉시) | 밀링·규율·CMM 보유 |
| 백플레이트·스티프너 | **빠름** | 평면밀링·평탄도 충족 |
| 구리 버스바 | **단기** | 밀링 가능, 도금 외주 |
| QD 금속 바디 | **단기~중기** | 정밀선반·진원도기 보유 |
| 매니폴드 (유체) | **견적·샘플 즉시 / 양산은 조건부** | 누수·압력기 보유, 단 고객 시험규격 정합 필요 |
| 콜드플레이트 (Cu) | **장기·조건부** | 구리 양산 수율 미검증 + 브레이징로 부재 |
| 콜드플레이트 (Al) | **장기·조건부** | FSW 설비 부재 |

### 4-3. 잔여 핵심 관문 3개

1. **thermal AVL 등재** — 대만 Tier-1 고객별 신규 승인벤더 등록 필수 (최대 관문)
2. **구리 마이크로채널 양산 수율** — 데이터 없이는 콜드플레이트 사업성 미판정
3. **접합 후공정** — 진공브레이징(Cu) 또는 FSW(Al) 설비 투자 또는 외주처 확보

### 4-4. 핵심 영업 메시지

> "당신들의 베트남 신공장 옆에서, 대중국 대비 ~50% 낮은 원가로,  
> IATF 16949 품질시스템과 누수·압력·CMM 검사 인프라를 갖춰,  
> 매니폴드·구조물을 즉시 납품 가능한 현지 Tier-2."
