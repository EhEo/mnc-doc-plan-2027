Level 0 - Context Diagram 설명

금형 품질관리 시스템의 전체 경계를 보여줍니다. 5개 외부 엔티티(설계팀, 가공팀, 품질팀, 설비팀, 주조설비)가 중앙 시스템과 데이터를 주고받습니다. 각 요소 위에 마우스를 올리면 상세 정보를 확인할 수 있습니다.

Level 1 - 주요 프로세스 분해

중앙 시스템을 5개 핵심 프로세스로 분해합니다: P1.설비정도관리, P2.가공품세팅관리, P3.가공품측정/검사, P4.T/O기술축적, P5.제조공정관리. 하단의 데이터 저장소(보라색)가 각 프로세스에서 생성/조회하는 데이터를 보여줍니다.

Level 2 - 가공품 측정/검사 상세 (P3 분해)

보고서의 핵심 개선 포인트인 "측정 의무화 + 검사 게이트"를 상세히 표현합니다. 미검사 전극은 EDM 투입이 금지되고, 미검사 코아는 금형 조립에 투입이 금지됩니다. 공차 초과(±0.02 기준) 시 자동으로 금형수정 프로세스로 연결됩니다.

Level 2 - T/O 기술축적 상세 (P4 분해)

보고서의 최종 목표인 "T/O 후 수정 Zero화"를 달성하기 위한 데이터 축적 및 피드백 루프를 보여줍니다. 10회 이상 T/O 데이터가 축적되면 위치/면적/형상별 수축률을 분석하여 설계 보정값을 자동으로 제안하는 구조입니다.
