## 1. 전체 요약 (Executive Summary)

본 자료 2건은 심천 모더바오(模德宝, MoldBao)가 제안한 **금형 공장용 MES(Manufacturing Execution System) — 模云 + MFMS** 솔루션의 두 가지 핵심 정보를 담고 있습니다.

* **자원평가 PPT**는 약 **980대 CNC 설비**가 가동되는 금형 공장에 모덕보 MES를 구축할 때 필요한 **네트워크 토폴로지 · IPC(공업용PC) · 서버 사양 · 사무망/공업망 물리적 격리 방안**을 제시합니다.
* **표준 모듈 Excel**은 모덕보 MES가 기본 제공하는 **22개 L1 대분류 · 약 130개 L2 중분류 · 259개 L3 세부 기능**의 전수 목록과 각 기능 설명을 포함하는 **솔루션 명세서(SOW용 베이스라인)** 입니다.

### 1-1. 핵심 메시지

| 항목 | 내용 |
|------|------|
| 솔루션 명 | 模云 (智能制造系统) + MFMS (자동화 라인 제어) |
| 적용 규모 (PPT 예시) | CNC 980대, 1대당 0.5 Mbps × 980 = 약 **500 Mbps 네트워크 트래픽** |
| 네트워크 구조 | 200대당 IPC 1대 그룹화, IPC는 **이중 NIC**로 공업망/사무망 **물리적 격리** |
| 서버 구성 | 물리 또는 가상 1대 (20코어/64GB RAM/SSD 4×960GB) |
| IPC 구성 | 研华 MIC-77H 6대 (5조 + 예비 1대) |
| 단말 (선택) | Win 태블릿 1920×1080 / 8GB / 256GB SSD |
| 솔루션 기능 범위 | 시스템 설정·프로젝트·CAD/CAM·BOM·계획·MES 실행·QC·구매·창고·钳工·시모·교부·설비감시·자산관리 등 **22개 모듈 全업무 커버** |

### 1-2. 의사결정 시사점

1. **네트워크 인프라가 사전 조건**: 모든 유선·무선 네트워크는 **고객(M&C)** 책임으로 구축해야 합니다 (PPT 명시). 5월 미팅 전에 베트남 법인 IT팀이 사전 검토 필요.
2. **서버 투자 규모 예측치**: 서버 1대 4.5만 위안 + IPC 6대 6만 위안 + 태블릿 N대 0.5만 위안 = 하드웨어만 약 **10.5만 위안 + α (≈ USD 14,500)** 규모.
3. **기능 범위는 매우 광범위**: 22개 모듈은 단순 MES를 넘어 **PLM(설계)·APS(계획)·CAM(가공)·QC·창고·구매·외주·교부·설비모니터링** 까지 **금형 회사용 ERP-MES 통합 패키지** 성격. 도입 시 **모듈 단계별 PoC + 우선순위화**가 필수.
4. **중국어 UI / 표준 워크플로우 의존**: 베트남 현지 운영을 위해서는 **언어 현지화·SLA·데이터 백업 정책**의 별도 합의가 필요 (이전 보고서 `20260426_모덕보_MES_회사소개_상세분석보고서.docx`의 SWOT 분석과 일치).

## 2. 문서 ① — 服务器资源评估.pptx (서버 자원평가서)

### 2-1. 문서 개요

* **장수:** 3장
* **언어:** 중국어 (간체)
* **목적:** 금형 공장에 모덕보 MES 도입 시 필요한 **서버·네트워크·IPC 사양**과 **이중 네트워크 격리 아키텍처**를 제안

### 2-2. 슬라이드별 상세

#### 슬라이드 1 — 모덕보 시스템 네트워크 아키텍처와 제안 (模德宝系统网络架构与建议)

* 사용자 → 핵심 3계층 스위치(三层交换机) → 하위 스위치 6대 → IPC(工控机) 5대
* IPC 1대당 **CNC 200대 데이터 수집** 담당
* 사용자는 PC, 태블릿, 전자 칸반(看板)으로 시스템 접속
* **고객사(M&C)** 가 모든 유선·무선 네트워크 구축 담당 (모덕보는 소프트웨어/IPC만 제공)

#### 슬라이드 2 — 네트워크 연결 구성도 (网络连接示意图)

이중 망(공업/사무) 물리적 격리 구조를 다이어그램으로 도식화.

| 구분 | 구성 요소 |
|------|-----------|
| 네트워크 캐비닛 | WIFI POE 스위치 |
| IPC | **이중 NIC(双网卡)** — 두 네트워크에 동시 연결 |
| 공업 LAN (工业局域网) | SCADA 스위치 3대 → 설비/CNC 직결 |
| 사무 LAN (办公局域网) | 보안성 우선, 태블릿은 WIFI 연결, 공업망과 **물리적 격리** |
| 서버 캐비닛 | 模云 智能制造系统 서버 |

> **핵심 보안 원칙**: 공업망과 사무망은 **공유 스위치 없이** 물리적으로 분리하며, IPC만이 이중 NIC로 양망 사이를 중계.

#### 슬라이드 3 — 솔루션 설계 설명 및 서버 구성 (方案设计说明与服务器配置)

##### 네트워크 대역폭 산정 (예시: 980대 CNC)

```
필요 대역폭 = 980대 × 0.5 Mbps/대 = 490 Mbps  (≈ 500 Mbps)
IPC 1대당 처리량 = 200대 × 0.5 Mbps = 100 Mbps  (네트워크 병목 방지)
```

##### 하드웨어 구성 (980대 CNC 기준)

| 카테고리 | 사양 | 수량 | 단가(예산) | 비고 |
|----------|------|------|------------|------|
| **태블릿** (선택) | Win OS, 1920×1080, 8GB+ RAM, 256GB SSD | N대 (필요 수량) | **0.5만 위안/대** | 기술자 프로그램 일괄 업로드용 |
| **IPC (工控机)** | 研华(Advantech) **MIC-77H** I5-10500 / 16GB / 256GB MSATA / Win10 64bit / 19V 전원 | **6대** (5조 운영 + 예비 1대) | **1만 위안/대** | 200대 CNC당 1대 |
| **서버** (물리 또는 VM) | 2.4GHz **20코어 이상** / 32GB ×2 = **64GB RAM** / **960GB SSD ×4** | **1대** | **4.5만 위안** | 全 SSD 구성 |

##### 합산 하드웨어 예산 (예시)

```
서버:    4.5만 위안 × 1대 =  4.5만 위안
IPC:    1.0만 위안 × 6대  =  6.0만 위안
태블릿:  0.5만 위안 × N대  = (별도)
─────────────────────────────────────
소계 (서버+IPC):           10.5만 위안 (≈ USD 14,500)
```

> ⚠️ **베트남 법인 적용 시 검토 필요사항**
> 1. M&C 베트남 법인의 CNC 보유 대수에 맞춰 IPC 수량 재산정 필요 (현재 모덕보 견적은 980대 기준)
> 2. 设备數 < 200대인 경우 IPC 1대로 운영 가능 → 비용 절감 여지
> 3. 서버는 물리/가상 모두 가능 → 본사 IDC 가상화 자원 활용 시 비용 절감
> 4. UPS, 백업 서버, 방화벽 등 부가 인프라는 모덕보 견적에 미포함 (별도 산정)

#### ⑮ 钳工管理 (Bench-work 관리)

## 4. 두 문서의 연계 관점

| 측면 | 서버평가 PPT | 표준모듈 Excel |
|------|--------------|----------------|
| 다루는 계층 | **인프라 (HW/Network)** | **소프트웨어 (기능)** |
| 산출물 | 서버·IPC·태블릿 BOM, 네트워크 토폴로지 | L1~L3 기능 마스터 (SOW 베이스라인) |
| 계약 시 활용 | **하드웨어 견적·환경 조건** 산정 근거 | **기능 매트릭스** (Out-of-the-box vs 커스터마이징 식별) |
| 누락된 공통 항목 | UPS·백업·방화벽·DR 정책 / 단가 화폐(CNY)·환율 / SLA | UI 언어(중국어) 한국어/영어/베트남어 가능 여부 / 모바일 앱 / API/IF 사양 / 권한 정책 |

### 4-1. 매핑 — "서버 1대"가 지원해야 하는 22개 모듈 워크로드

서버 사양 (2.4GHz 20core, 64GB RAM, SSD 4×960GB)은 다음 부하를 동시에 처리하는 전제로 산정:

1. **设备监控 (㉑)** — 980대 CNC × 0.5Mbps 실시간 데이터 수집·집계 (가장 높은 I/O 부하)
2. **智能制造 (⑨) + APS (⑦)** — 工單/배정/排程 자동연산 (CPU 집중)
3. **MES Core (⑨ 制造执行)** — RFID/Barcode 조회, 가공 보고, 부품 QC (트랜잭션 부하)
4. **CAD/CAM (④⑧)** — BOM·도면·程序 file 저장, **NX 연동 BOM 도출** (대용량 파일 I/O)
5. **품질·창고·구매·외주·설비자산** 트랜잭션 처리

→ 980대 환경에서 **64GB RAM은 마진이 크지 않음**. M&C 도입 시 CNC 수량 산정 후 **메모리 +50% 옵션 견적** 추천.

## 6. 결론

본 2건의 문서는 모덕보 MES 솔루션 도입 검토의 **인프라(HW/Network) + 기능(SW)** 양 축을 모두 커버하는 표준 자료입니다.
