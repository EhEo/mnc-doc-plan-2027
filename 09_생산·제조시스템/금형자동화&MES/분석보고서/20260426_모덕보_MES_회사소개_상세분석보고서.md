## 2. 회사 소개 — Page 03 (01 模德宝介绍)

### 2.1 회사 简介 (Profile)

소개서 본문의 핵심 키워드를 재구성하면 다음과 같다.

- 2012년 심천 설립, 모구(금형) 및 정밀 제조 산업의 **数字化(디지털화)·自动化(자동화)·智能化(지능화)** 솔루션을 **一站式(원스톱)** 으로 제공.
- "客户优先(고객 우선)"을 경영 이념으로, **公司化(회사화)·专业化(전문화)·规范化(표준화)·智能化(지능화)** 의 4化 운영을 추구.
- 자체 개발 핵심 제품군: **数据交互平台(데이터 통합 플랫폼) · CAM 智能编程(CAM 지능 가공경로) · EAM 智能设备(EAM 지능 설비) · GAS 智能仓储(GAS 지능 창고) · PDM 产品数据管理(PDM) · MES · AGV 智能物流系统** 등.
- 6축 로봇 자동화 셀 + MES + MFMS 결합으로 **무인화·24시간 가동 가능 智慧工厂(스마트팩토리)** 구축이 가능함을 자칭.

## 3. 模云 智能制造云平台 — Page 04~08 (02 핵심 플랫폼)

### 3.1 플랫폼 전체 아키텍처 (Page 04)

모덕보의 핵심 SaaS형 MES 브랜드는 **模云(MoYun, "모운/금형클라우드")** 이다. 인포그래픽은 클라우드 데이터 허브를 중심으로 5개 도메인 모듈이 양방향 연계되는 구조로 표시되어 있다.

| 모듈 | 코드 | 핵심 역할 (소개서 표기 요약) |
| --- | --- | --- |
| **A. 研发管理** (R&D Management) | A | 项目设计·智能设计·BOM 관리·工艺设计·智能编程 |
| **B. 计划排产** (Plan & APS) | B | 自动排产·车间计划·任务分配·工序排程·生产工时 분석 |
| **C. 智能制造** (Intelligent Manufacturing) | C | 数字化生产管理·DEC接口·电极/工件/CNC/EDM/CMM 자동화 통제 |
| **D. 经营管理** (Business Management) | D | 业务·采购·库存(仓库)·成本·设备·夹具·OEE 등 ERP 영역 |
| **E. 协同制造** (Collaborative Manufacturing) | E | 厂内·供应商·客户 데이터 통합, 다공장(多工厂)/외주 협업 |

부속 모듈로 **F. 模云 APP** (모바일 실시간 모니터링)이 있다.

> **구조적 의의:** "**연구개발(PLM/CAD) → 계획(APS) → 실행(MES) → 경영(ERP) → 협업(SCM/SRM/CRM)**" 까지 모구 산업 특화 풀스택을 단일 클라우드로 묶은 것이 차별점. 일반 범용 MES(예: SAP ME, Aegis)와 달리 **모구·정밀가공 도메인 특화** 라는 점이 핵심 마케팅 포인트로 보인다.

### 3.6 E. 协同制造 (Collaborative Manufacturing) — Page 08 좌측

핵심 키워드: **"统一数据交互平台"** (통합 데이터 교환 플랫폼).

- 三类参与方 (3 유형 참여자): **厂内供应商 · 供应商 · 客户**
- 5계층 통합 구조 (소개서 인포그래픽):
  - **设备层** (PLC, SCADA, DCS, FCS, CDN)
  - **控制层** (制造 실행 통제)
  - **工厂层** (车间·拉线·设备 통합)
  - **企业层** (MES, ERP, PDM, APS, SRM, CRM)
  - **生态层** (供应商·客户·다공장)

이 구조는 **ISA-95 5계층 모델**과 사실상 일치하며, 모덕보가 표준 산업 자동화 아키텍처를 따르고 있음을 보여준다.

### 4.2 模德宝 智能机器人 CCR — Page 09 우측

CCR(코드 명) = 모덕보의 자체 6축 로봇 셀의 브랜드.

| 구분 | 사양/특징 (소개서 표기) |
| --- | --- |
| 핵심 컨셉 | **"机床·机器人·系统 一体化"** (공작기계·로봇·시스템 일체화) |
| 머신 수 | **1+1 多机 CNC** 등 (1대 또는 다대) |
| 료架 (소재 랙) | 抽屉式(서랍식) CCR 자동 랙 |

> **M&C 인사이트:** 천진 迈凯 자동화 라인이 1+1 또는 1+다 머신 구성을 선택할 때 CCR이 직접 호환되는지 확인 필요. CCR 자체 도입보다는 **MFMS 소프트웨어 + 모덕보 인증 외부 로봇** 조합이 비용·유지보수 측면에서 더 합리적일 가능성도 평가 필요.

### 4.3 模德宝 柔性制造自动化系统 (MFMS) — Page 10

**MFMS = Modebao Flexible Manufacturing System.** 본 자료에서 가장 구체적으로 소개된 라인 단위 통제 시스템이다.

소개서 인포그래픽에 등장하는 9개 통제 모듈:

| 모듈 | 한글/역할 |
| --- | --- |
| 操作执行 (Operation Execution) | 설비 모형, 작업 다운로드, 작업 시뮬레이션, 작업 상태 표시, 작업 추적, 도구 보충 등 |
| **AGV 自动物流** | AGV 호출·자동조도·智능 이송·라인 간 무인 운반 |
| 信息推送 (Push Notifications) | 생산 상태 알림, 고장 푸시, 메일·SMS·WeChat 통보 |
| 电子看板 (Andon Board) | 라인 실시간 시각화, 진척·이상·생산량 보드 |
| 控制台 (Control Console) | 통제 콘솔 |
| 数据报表 (Data Report) | 가동률·생산량 자동 리포트 |
| 程式管理 (Program Management) | NC 프로그램 자동 다운로드·버전 관리 |
| 订单管理 (Order Management) | 작업 주문 관리 |
| 料架管理 (Rack Management) | 자동 랙 위치·수량 관리 |

소개서 우측에 표시된 3종 화면샷:

1. **图形化控制界面 / 人机交互·操作简单** — 그래픽 통제 화면, 인간-기계 상호작용 간소화.
2. **零件状态实时监控·进度展示一目了然** — 부품 상태 실시간 모니터링, 진척 한눈에 확인.
3. **设备稼动率统计·加工效率提升** — 설비 가동률 통계, 가공 효율 향상.

> **M&C 인사이트:** **MFMS는 천진 迈凯 자동화 라인의 "두뇌"** 가 될 수 있다. 천진 迈凯 라인이 하드웨어 중심(로봇·CNC·EDM·CMM·AGV)이라면, MFMS가 그 위에서 **작업지시·OEE·이상 알림**을 통합 수행하는 "라인 OS" 역할을 한다.

## 7. 모덕보 솔루션 SWOT 분석 (M&C 관점)

### 7.1 강점 (Strengths)

1. **모구·정밀가공 산업 특화 풀스택**: R&D부터 협업까지 단일 클라우드로 운영 가능 → 일반 MES 대비 도입 갭 작음.
2. **자체 6축 로봇 셀 + MFMS 보유**: 하드웨어·소프트웨어 일체 공급 가능 → SI 리스크 단일화.
3. **6개 거점 (천진 포함)**: 천진 迈凯 자동화 라인과 지리적 시너지.
4. **80+ 고객사 + ISO27001 등 인증**: SaaS형 MES 도입 시 보안 리스크 완화.
5. **대형 고객 레퍼런스**: Midea, GREE, PHILIPS, Hisense, MOLEX 등 글로벌 브랜드.

### 7.2 약점 (Weaknesses)

1. **언어**: 인터페이스·문서 모두 **중문 위주**. 한국어/베트남어 지원 여부 미확인.
2. **클라우드 의존성**: 모운(模云)이 SaaS 기반이라면 **베트남 인터넷 환경(특히 정전·BCP)** 대응 검증 필요.
3. **자동차 산업 사례 노출 부족**: 본 자료의 사례는 가전·전자 위주. M&C가 속한 자동차 부품 1차 협력사 사례 별도 요청 필요.
4. **가격 정보 미공개**: 카탈로그형 소개서로 라이선스·구축비·연간 운영비 산정 불가.
5. **글로벌 SI/PM 역량 미확인**: 해외(특히 베트남) 프로젝트 PM 운영 경험 자료 부족.

### 7.3 기회 (Opportunities)

1. **천진 迈凯 라인 도입 시 결합 SI**: 라인 + MFMS + 모운 클라우드를 일괄 패키지로 도입 시 **자동화 + 디지털화 동시 실현**.
2. **삼성 브라켓 수주 전략과 연계**: 모덕보 MES로 OEE·품질·납기를 실시간 가시화 → 삼성에 자동화 + 디지털 라인 어필 가능.
3. **다공장 통합 (한국·베트남·중국)**: 协同制造 모듈 활용 시 3국 다공장 동시 모니터링 시나리오 실현 가능.
4. **AS9100D 디지털 전환 연계**: 항공 인증 추진 중인 M&C에 데이터 트레이서빌리티 자동화 솔루션으로 활용 가능.

### 7.4 위협 (Threats)

1. **중국 SaaS 데이터 주권**: 모운 클라우드가 중국 본토 호스팅이라면 **EU GDPR · 미국·한국 고객사 데이터 정책** 위반 리스크 존재.
2. **공급사 종속(Lock-in)**: 모운 + MFMS + CCR 일괄 도입 시 향후 변경 비용 큼.
3. **사후 지원 SLA**: 베트남 거점 부재 → 본사·천진 거점 의존 시 응답 시간 지연 가능.
4. **경쟁 솔루션**: SAP DM, Siemens Opcenter, Aegis FactoryLogix, Hexagon SmartFactory 등 글로벌 솔루션과의 비교 필요.

## 9. 결론 및 종합 의견

모덕보(模德宝, Modebao)는 **2012년 설립된 중국 심천 본사의 모구·정밀제조 산업 특화 디지털 전환 솔루션 공급사**로, **MES(模云) + 6축 로봇 자동화 셀(CCR) + 라인 단위 유연 자동화 시스템(MFMS)** 의 3대 솔루션을 단일 공급사가 제공할 수 있는 드문 업체이다. 천진 거점 보유 → 천진 迈凯 자동화 라인과의 결합 시너지가 크고, 80+ 글로벌 고객 레퍼런스(Midea·GREE·PHILIPS·MOLEX·Innolux 등)는 신뢰성을 뒷받침한다.

다만, **다국어 지원·베트남 현지 SLA·가격 투명성** 측면에서 검증이 필요하다. 본 카탈로그 자체로는 도입 결정의 근거로 부족하며, **(i) 천진 PoC 사이트 견학, (ii) 다국어 인터페이스 데모, (iii) 5년 TCO 견적, (iv) 베트남 데이터 호스팅 정책** 등 4가지를 추가로 확보한 후 의사결정을 권고한다.

천진 迈凯 자동화 라인 도입과 결합할 경우, 모덕보 MFMS + 模云 SaaS는 M&C의 **"하드웨어 자동화 + 디지털 통합 라인"** 구상의 강력한 후보가 될 수 있다.
